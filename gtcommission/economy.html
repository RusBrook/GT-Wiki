多经济 ​

GTCommission 可以同时配置多种货币。玩家发布悬赏时在奖励设置界面选择币种，奖励托管、接取押金、追加小费、获胜发放和退款始终使用该悬赏记录的同一种币。

配置位置：

yaml
economy:
  default: money
  currencies:
    money:
      name: "金币"
      provider: vault
    points:
      name: "点券"
      provider: playerpoints

字段说明 ​

字段说明
default发布悬赏时默认选中的币种 ID
currencies.<ID>.nameGUI 和消息中显示的货币名称
currencies.<ID>.provider实际使用的经济来源

币种 ID 由服主自己填写，例如 money、points、guild_coin。悬赏模板通过 economies 决定该类型允许选择哪些币种。

Vault ​

yaml
currencies:
  money:
    name: "金币"
    provider: vault

需要：

  1. Vault。
  2. 任意 Vault 经济插件，例如 CMI Economy、XConomy、EssentialsX Economy。
  3. /gtcom debug 中 money=可用。

Vault 经济直接调用经济接口，不执行扣款或加款命令。

PlayerPoints ​

yaml
currencies:
  points:
    name: "点券"
    provider: playerpoints

安装 PlayerPoints 后重启服务器，再用 /gtcom debug 检查 points=可用。

DreamPoints ​

yaml
currencies:
  dream:
    name: "梦境点"
    provider: dreampoints

安装 DreamPoints 后使用。显示名称可以自己改，不要求和经济插件原名一致。

自定义经济 ​

没有现成经济来源时，不写 provider，填写余额 PAPI 变量和增减命令：

yaml
currencies:
  guild_coin:
    name: "公会币"
    balance-placeholder: "%guild_coin_amount%"
    take-commands:
      - "guildcoin take {player} {amount}"
    give-commands:
      - "guildcoin give {player} {amount}"

要求：

  • 安装 PlaceholderAPI。
  • balance-placeholder 返回纯数字，例如 1250 或 1250.5。
  • 扣除命令和增加命令都能由控制台执行。
  • 命令中的玩家名和数量使用 {player}、{amount}。

可用变量：

变量内容
{player}玩家名
{uuid}玩家 UUID
{economy}币种 ID
{amount}本次增减数量
{reason}扣款、奖励、押金或退款原因

未写执行者前缀的命令默认由控制台执行。需要玩家执行时写：

yaml
take-commands:
  - "player:currency pay {amount}"

自定义经济通过命令增减，服主需要先在控制台手动测试命令是否正确。

限制悬赏可用币种 ​

yaml
bounties:
  monster_hunt:
    economies: [money, points]

该悬赏只能在金币和点券之间切换。

只允许金币：

yaml
economies: [money]

允许公会币：

yaml
economies: [money, guild_coin]

列表中的币种必须已经写在 config.yml 的 economy.currencies 下。不可用的币种不会出现在发布界面中。

检查命令 ​

text
/gtcom debug

示例：

text
经济: money=可用, points=可用, guild_coin=不可用

自定义经济显示不可用时依次检查：

  1. PlaceholderAPI 是否安装并启用。
  2. balance-placeholder 是否为空。
  3. take-commands 是否至少有一条命令。
  4. give-commands 是否至少有一条命令。
  5. 悬赏模板的 economies 是否写了正确币种 ID。

常用 PAPI ​

text
%gtcommission_economies%
%gtcommission_economy_name_money%
%gtcommission_economy_available_money%
%gtcommission_economy_balance_money%

完整列表见 PAPI 变量。
