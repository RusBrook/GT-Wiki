安装、商户与监听 App ​

安装要求 ​

项目要求
服务端版本1.12.2 到当前最新版
核心正常运行并完成授权的 GTCore
安卓设备能长期运行 GT收款守护，并允许读取微信、支付宝到账通知
收款码微信、支付宝个人收款码 PNG 或 JPEG 图片

GTPay 由 GTCore 自动加载，不需要把 GTPay JAR 放入 plugins。

创建服务器凭证 ​

私聊机器人：

text
创建GTPay 服务器名称

示例：

text
创建GTPay 生存一区

机器人只会给已经拥有 GTPay 的 QQ 创建凭证。未拥有 GTPay 时会返回：

text
你当前未拥有GTPay

返回内容中四项配置的用途：

配置填写位置
merchant_id服务端本地管理页、监听 App
server_id服务端本地管理页
server_key服务端本地管理页
monitor_key服务端本地管理页、监听 App

密钥只通过私聊查询，不要发到群内、工单截图或公开配置中。

多服务器配置 ​

同一服主可以创建多个服务器：

text
创建GTPay 生存一区
创建GTPay 生存二区
创建GTPay RPG一区

每个服务器都要使用自己对应的四项配置。不要把一区的 server_id、server_key 与二区的 merchant_id 混用。

跨服同步的多个区 ​

5 台独立服务端如果属于同一个跨服网络，并且需要合并累计赞助、排行和礼包限购，5 台都填写同一套 GTPay 凭证：

text
merchant_id  相同
server_id    相同
server_key   相同
monitor_key  相同

这表示这些区在 GTPay 中属于同一个收款主体。各区仍然是独立服务端，订单由创建订单的那台服务端负责查询和发放，其他区不会抢发订单。监听 App 使用同一个 merchant_id 和 monitor_key 即可。

在 5 台服务端的 plugins/GTPay/config.yml 中，把存储方式改成 MySQL 或 Redis，并填写同一个数据库或 Redis：

yaml
storage:
  mode: "mysql"
  node-id: "auto"
  cluster-id: "auto"

cluster-id 使用 auto 时按 merchant_id 隔离。同一组跨服服务器保持一致；不要给同一组服务器填写不同的 cluster-id。node-id 保持 auto，每台服务端会根据 GTCore 设备和服务端端口生成自己的节点标识。

存储配置由 GTPay 保存，MySQL、Hikari、Redis 和 Lettuce 运行库由 GTCore 提供，不需要额外上传数据库驱动 JAR。修改存储方式、数据库或集群标识后，重启对应的 Minecraft 服务端。

同步内容包括：

  • 已完成订单。
  • 礼包个人购买上限和全服购买上限。
  • 永久、日、周、月、年和活动累计赞助金额。
  • 累计赞助排行和 PAPI 排名变量。
  • 累计赞助奖励领取记录。

通常在同步间隔内生效，默认间隔为 10 秒。

如果多个区需要分别统计、分别查看订单或分别使用不同收款主体，为每个区创建独立的 GTPay 凭证，并使用独立的 cluster-id 或独立数据库。

使用 local 存储时，订单和累计数据只保存在当前服务端，不会跨服同步。

打开本地管理页 ​

在 Minecraft 服务器控制台执行：

text
gtpay web open

控制台会返回一次性访问地址。在运行 Minecraft 服务端的机器上打开该地址。

本地管理页包含：

  • 概览。
  • 连接配置。
  • 本地、MySQL、Redis 存储配置。
  • 点券充值配置。
  • 礼包配置。
  • 累计赞助配置。
  • 多文件 GUI 配置。
  • 近期订单与发放重试。

页面不显示服务地址，也没有服务地址填写项。

完成配置后可以关闭：

text
gtpay web close

查看管理页状态：

text
gtpay web status

放置收款码 ​

默认文件位置：

text
plugins/GTPay/qrcode/wechat.png
plugins/GTPay/qrcode/alipay.png

图片要求：

  • 使用微信、支付宝正常可用的个人收款码。
  • 使用正方形 PNG。
  • 图片边缘不要带大段文字、广告或复杂边框。
  • 文件不要超过 4 MB。
  • 图片必须放在 qrcode 文件夹中。

如果要修改文件名，在 config.yml 或本地管理页修改：

yaml
qrcode:
  directory: "qrcode"
  wechat: "wechat.png"
  alipay: "alipay.png"
  display-in-map: true

收款码只保存在服主服务器本地，不需要上传。

配置监听 App ​

在安卓设备安装并启动 GT收款守护。

App 中只需要填写：

text
merchant_id
monitor_key

然后完成以下设置：

  1. 授予通知使用权。
  2. 允许 App 在后台运行。
  3. 关闭系统对该 App 的省电限制。
  4. 保证微信、支付宝能正常显示到账通知。
  5. 确认 App 显示连接成功。

App 不填写激活码、server_key 或后台地址。
