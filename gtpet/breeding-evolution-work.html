本页目录

繁育、进化、工作与奖励 ​

本页介绍繁育条件、基因、进化路线、工作周期、装备要求和奖励领取。

主要文件：

text
plugins/GTCore/modules/GTPet/breeding.yml
plugins/GTCore/modules/GTPet/jobs.yml
plugins/GTCore/modules/GTPet/systems.yml
plugins/GTCore/modules/GTPet/templates.yml

开启繁育 ​

breeding.yml：

yaml
schema: 1

settings:
  enabled: true
  max-generation: 3
  forbid-shared-parents: true
字段说明
enabled是否允许繁育
max-generation允许产生的最高世代
forbid-shared-parents是否禁止同父母的宠物互相繁育

繁育双方必须：

  • 属于同一玩家。
  • 使用同一模板。
  • 处于已收回状态。
  • 不是同一只宠物。
  • 没有繁育冷却。
  • 血缘关系符合设置。
  • 下一代不超过 max-generation。

配置基因 ​

yaml
genes:
  attack:
    alleles:
      - A
      - a
    dominant:
      - A
  vitality:
    alleles:
      - V
      - v
    dominant:
      - V
  scavenger:
    alleles:
      - S
      - s
    dominant:
      - S

模板中给宠物初始基因：

yaml
pets:
  fire_wolf:
    genes:
      - id: attack
        alleles: A/a
      - id: vitality
        alleles: V/v
      - id: scavenger
        alleles: S/s

基因对应的属性加成位于 attributes.yml：

yaml
sources:
  genes:
    attack:
      A:
        attack: 2.0
      a:
        attack: 0.5

执行繁育 ​

GUI：

  1. 两只宠物都先收回。
  2. 打开 /gtpet。
  3. 进入第一只宠物详情页。
  4. 打开繁育页。
  5. 选择另一只可配对宠物。

命令：

text
/gtpet breed <宠物短ID> <另一只宠物短ID>

成功后会生成一只新宠物。执行 /gtpet pets 查看幼体短 ID、品质和世代。

完整进化路线 ​

yaml
evolutions:
  guardian_ii:
    display-name: '&b二代守护进化'
    from-generation: 1
    to-generation: 2
    min-level: 20
    min-intimacy: 100.0
    required-traits:
      - loyal
    grant-traits:
      - guardian
    grant-skills:
      - id: guardian_heal
        level: 1
    actions:
      - '[message]&b宠物完成了二代守护进化。'
字段说明
display-nameGUI 显示名称
from-generation进化前世代
to-generation进化后世代
min-level最低等级
min-intimacy最低亲密度
required-traits必须拥有的特质
grant-traits成功后增加的特质
grant-skills成功后增加的技能和等级
actions成功后执行的动作

模板必须允许这条进化路线：

yaml
pets:
  fire_wolf:
    evolutions:
      - guardian_ii

执行进化 ​

GUI：详情页 -> 繁育页 -> 进化页。

命令：

text
/gtpet evolve <宠物短ID> guardian_ii

进化前先收回宠物。成功后执行 /gtpet pets，确认世代改变。

配置工作 ​

jobs.yml：

yaml
schema: 1

jobs:
  patrol:
    display-name: '&b巡逻护卫'
    provider: NATIVE
    cycle-seconds: 300
    max-cycles: 96
    energy-per-cycle: 1.0
    experience-per-cycle: 2
    required-traits:
      - loyal
    rewards:
      - '[message]&a巡逻工作结算完成。'
字段说明
display-name工作页显示名称
provider工作类型
cycle-seconds每个工作周期的秒数
max-cycles一次最多累计多少周期
energy-per-cycle每周期消耗能量
experience-per-cycle每周期获得经验
required-traits必须拥有的特质
required-equipment-slot必须已装备的槽位
rewards领取时执行的奖励动作

工作类型 ​

provider用法
NATIVEGTPet 普通工作
GTGATHER使用 GTGather 联动工作
GTOFFLINE使用离线工作模式

需要工具的工作 ​

yaml
gather_assist:
  display-name: '&a采集助手'
  provider: GTGATHER
  cycle-seconds: 300
  max-cycles: 96
  energy-per-cycle: 2.0
  experience-per-cycle: 3
  required-traits:
    - worker
  required-equipment-slot: tool
  rewards:
    - '[message]&a采集工作结算完成。'

模板必须允许该工作：

yaml
pets:
  pack_horse:
    work-jobs:
      - gather_assist
    equipment-slots:
      - tool

开始工作前，在 tool 槽位穿戴符合规则的宠物工具。

联动开关 ​

systems.yml：

yaml
integrations:
  gtgather:
    enabled: false
  gtmobdrops:
    enabled: false
  gtoffline:
    enabled: false
  mythicmobs:
    enabled: true
  groovy:
    enabled: true

使用 GTGATHER 工作前，将 gtgather.enabled 改为 true，并确认对应插件已安装。使用 GTOFFLINE 工作前，将 gtoffline.enabled 改为 true。

修改后执行：

text
/gtpet reload

开始和停止工作 ​

开始：

text
/gtpet work start <宠物短ID> patrol

停止：

text
/gtpet work stop <宠物短ID>

也可以打开宠物详情页进入工作页操作。

工作开始前检查：

  • 模板的 work-jobs 包含工作 ID。
  • 宠物拥有 required-traits。
  • 需要装备槽时，该槽位已经穿戴物品。
  • 对应联动已开启。
  • 宠物状态允许开始工作。

领取奖励 ​

text
/gtpet claim <宠物短ID>

领取指定奖励：

text
/gtpet claim <宠物短ID> <奖励ID>

工作页也可以点击领取。领取成功后执行 /gtpet pets，待领奖励数量应减少。

待领奖励上限位于 systems.yml：

yaml
work:
  max-pending-rewards: 128

达到上限后，玩家需要先领取奖励。

工作周期示例 ​

配置：

yaml
cycle-seconds: 300
max-cycles: 96
energy-per-cycle: 2.0
experience-per-cycle: 3

含义：

  • 每 300 秒结算一个周期。
  • 最多累计 96 个周期。
  • 每周期消耗 2 点能量。
  • 每周期获得 3 点工作经验。

如果宠物只完成 10 个周期，则消耗 20 点能量并获得 30 点经验，再生成对应奖励。

完整繁育验收 ​

  1. 发放两只相同模板宠物。
  2. 将两只宠物全部收回。
  3. 执行 /gtpet breed <第一只> <第二只>。
  4. 执行 /gtpet pets，确认出现新幼体。
  5. 检查幼体世代、品质和基因。
  6. 将宠物提升到进化等级并满足特质、亲密度要求。
  7. 执行 /gtpet evolve <宠物> guardian_ii。
  8. 确认世代、特质和技能发生变化。

完整工作验收 ​

  1. 为模板加入 patrol 工作。
  2. 执行 /gtpet reload。
  3. 发放测试宠物，确认拥有 loyal 特质。
  4. 执行 /gtpet work start <宠物> patrol。
  5. 等待至少一个周期。
  6. 执行 /gtpet work stop <宠物>。
  7. 执行 /gtpet pets，确认待领奖励增加。
  8. 执行 /gtpet claim <宠物>。
  9. 确认奖励动作执行，待领奖励减少。

排错 ​

无法繁育 ​

  • 两只宠物必须是同一模板。
  • 两只宠物必须属于同一玩家。
  • 两只宠物必须已收回。
  • 检查繁育冷却、世代上限和血缘限制。

无法进化 ​

  • 模板必须列出该进化 ID。
  • 检查当前世代、等级、亲密度和所需特质。
  • 进化时宠物应处于已收回状态。

无法开始工作 ​

  • 模板必须列出工作 ID。
  • 检查所需特质。
  • 检查必需装备槽。
  • 检查对应联动开关和依赖插件。

没有奖励 ​

  • 确认至少完成一个工作周期。
  • 检查宠物是否有足够能量。
  • 检查 rewards 列表是否为空。
  • 执行 /gtpet pets 查看待领奖励数量。
