GTPet 使用教程 ​

本页带你从安装完成走到成功发放、召唤和操作第一只宠物。所有配置文件都位于：

text
plugins/GTCore/modules/GTPet/

安装 ​

  1. 安装服务器对应版本的 GTCore。
  2. 将 GTPet 模块 JAR 放入 GTCore 的模块目录。
  3. 启动服务器，等待控制台出现 GTPet 配置加载成功提示。
  4. 关闭服务器或确认没有玩家正在操作宠物后，再修改生成的 YAML。

支持的服务器范围包括 Spigot 1.12.2、CatServer 1.12.2、Purpur、Paper 和 Folia。Java 版本按服务器核心要求选择。

配置文件 ​

首次加载后会生成以下文件：

文件配置内容
config.yml存储、宠物数量、下线收回、改名、模块开关
templates.yml宠物模板、品质池、基础属性、技能、基因、装备槽、工作
coefficients.yml战斗、移动、资源、成长、繁育和工作数值
overrides.yml按世界、模板、品质、姿态、权限等条件覆盖系数
messages.yml玩家提示、状态名称、品质名称、错误提示
skills.yml技能目标、消耗、冷却、范围和效果类型
breeding.yml基因、繁育限制和进化路线
attributes.yml属性成长、品质加成、基因/特质加成、装备属性名
display.ymlPLAYER 外观、移动同步和头顶信息
equipment.yml装备槽位置、允许物品、解锁条件和实体显示位置
jobs.yml工作类型、周期、消耗、经验和奖励
systems.yml战斗结算、PVP、成长、工作和联动开关
gui/*.yml宠物列表、详情、成长、繁育、进化、装备、技能和工作页面

第一次启动检查 ​

在控制台执行：

text
gtpet status
gtpet templates

正常结果：

  • ready 显示为 true。
  • 存储显示为本地、MySQL 或 Redis。
  • gtpet templates 能列出 starter_wolf、forest_ocelot、pack_horse、iron_guardian 和 player_companion。

如果 ready=false，先看同一时间的控制台报错。常见原因是 YAML 缩进错误、存储连接失败、模板引用了不存在的技能/装备槽，或配置值超出允许范围。

十分钟完成第一只宠物 ​

下面假设在线玩家名为 Steve。

1. 发放宠物 ​

在控制台或拥有 gtpet.admin.give 权限的管理员账号执行：

text
gtpet give Steve starter_wolf 1

管理员和玩家都会收到成功提示，其中包含这只宠物的短 ID。

2. 打开宠物界面 ​

玩家执行：

text
/gtpet

点击宠物条目进入详情页。详情页可以召唤/收回宠物、切换姿态、改名，并进入成长、繁育、进化、技能、装备和工作页面。

3. 召唤宠物 ​

可以在 GUI 中点击召唤，也可以执行：

text
/gtpet summon <宠物短ID>

预期结果：宠物出现在玩家附近，超过跟随距离后自动跟随，距离过远时返回玩家身边。

4. 切换姿态 ​

text
/gtpet stance <宠物短ID> DEFENSIVE

可用姿态由模板的 allowed-stances 决定：

姿态用途
PASSIVE不主动战斗，主要跟随主人
DEFENSIVE主人或宠物受到攻击时反击
AGGRESSIVE主动寻找允许攻击的目标
HOLD保持当前位置
WORK用于工作状态

5. 收回宠物 ​

text
/gtpet recall <宠物短ID>

主人下线时默认也会自动收回宠物：

yaml
pets:
  recall-on-owner-quit: true

常用命令 ​

玩家需要 gtpet.use 权限。

命令用途
/gtpet打开宠物主界面
/gtpet pets查看宠物短 ID、品质、等级、状态和姿态
/gtpet templates查看可用模板
/gtpet summon <宠物>召唤宠物
/gtpet recall <宠物>收回宠物
/gtpet revive <宠物>复活倒地宠物
/gtpet stance <宠物> <姿态>切换姿态
/gtpet rename <宠物> <名称>修改名称
/gtpet grow <宠物> <属性> <点数>分配潜能点
/gtpet reset <宠物>重置已分配的属性点
/gtpet skill cast <宠物> <技能>主动施放技能
/gtpet skill learn <宠物> <技能> [点数]学习或升级技能
/gtpet breed <宠物> <另一只宠物>繁育幼体
/gtpet evolve <宠物> <进化ID>执行进化
/gtpet equip <宠物> <槽位> <物品ID>从背包中按物品 ID 选择并穿戴装备
/gtpet unequip <宠物> <槽位>卸下装备
/gtpet work start <宠物> <工作ID>开始工作
/gtpet work stop <宠物>停止工作
/gtpet claim <宠物> [奖励ID]领取工作奖励

管理员权限：

权限用途
gtpet.admin.give发放宠物
gtpet.admin.reload重载配置
gtpet.admin.diagnostics查看状态、系数和 AI 诊断
gtpet.pvp.bypass绕过宠物 PVP 保护判断

同模板多只宠物 ​

同一玩家可以拥有多只相同模板的宠物。先执行：

text
/gtpet pets

再使用列表中的短 ID：

text
/gtpet summon a1b2c3d4
/gtpet rename a1b2c3d4 小白

如果模板名只匹配到一只宠物，也可以直接使用模板 ID；匹配到多只时必须使用短 ID。

修改配置并生效 ​

大多数玩法和 GUI 配置修改后执行：

text
/gtpet reload

重载成功后重新打开 GUI。已召唤的 PLAYER 宠物如果修改了皮肤、显示方式或逻辑实体，需要先收回再重新召唤。

以下配置修改后需要重启服务器或重新加载模块：

  • storage.backend
  • storage.namespace
  • MySQL/Redis 连接信息

完整验收 ​

  1. 执行 gtpet status，确认 ready=true。
  2. 执行 gtpet give Steve starter_wolf 1。
  3. 玩家打开 /gtpet，确认能看到宠物。
  4. 召唤宠物，走出 4 格以上，确认宠物开始跟随。
  5. 切换 PASSIVE、DEFENSIVE 和 HOLD，确认状态文字改变。
  6. 打开成长、技能、装备和工作页面，确认页面可以正常进入。
  7. 收回宠物并重新召唤，确认同一只宠物的等级、品质和装备没有变化。
  8. 重启测试服，再执行 /gtpet pets，确认宠物记录仍可读取。
