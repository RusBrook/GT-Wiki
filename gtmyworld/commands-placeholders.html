命令与 PlaceholderAPI 变量 ​

主命令：

text
/gtmyworld

别名：/gtmw、/myworld、/jiayuan。

玩家命令 ​

命令说明
/gtmw打开家园主界面
/gtmw create [模板ID]打开模板界面或直接创建
/gtmw home返回自己的家园
/gtmw visit [玩家]打开公开家园或访问指定玩家
/gtmw invite <玩家>邀请玩家加入，对方可点击聊天按钮接受
/gtmw accept接受邀请
/gtmw leave退出当前家园
/gtmw upgrade升级家园
/gtmw settings打开家园设置
/gtmw members打开成员与权限
/gtmw core打开家园核心
/gtmw core fuel <ID> [数量]投入核心燃料
/gtmw core refund <ID>取回自己的剩余燃料
/gtmw core redeem赎回核心
/gtmw setspawn设置家园传送点
/gtmw name <名称>修改家园名称
/gtmw description <介绍>修改家园介绍
/gtmw like为当前家园点赞
`/gtmw rank [levelmembers

具体操作是否开放由 permissions.yml 和家园个人权限共同决定。

管理命令 ​

命令权限说明
/gtmw template wandgtmyworld.admin.template获取模板选区工具
/gtmw template save [ID] [显示名称]gtmyworld.admin.template保存选区并登记模板名称；省略参数时按输入框提示完成
/gtmw template cleargtmyworld.admin.template清除选区
/gtmw admin reloadgtmyworld.admin重载普通配置
/gtmw admin statusgtmyworld.admin查看存储、家园数和节点

家园改名、修改介绍、设置传送点、邀请成员、升级、点赞和退出家园都可以从 /gtmw GUI 完成。公开家园与排行条目左键访问、右键点赞。

家园变量 ​

玩家自己所属家园使用：

text
%gtmyworld_has_realm%
%gtmyworld_id%
%gtmyworld_name%
%gtmyworld_owner%
%gtmyworld_description%
%gtmyworld_template%
%gtmyworld_level%
%gtmyworld_diameter%
%gtmyworld_server%
%gtmyworld_world%
%gtmyworld_members%
%gtmyworld_member_slots%
%gtmyworld_member_slots_free%
%gtmyworld_visits%
%gtmyworld_likes%
%gtmyworld_public%
%gtmyworld_status%
%gtmyworld_role%

当前所在家园在变量名后使用 current_：

text
%gtmyworld_current_name%
%gtmyworld_current_owner%
%gtmyworld_current_level%
%gtmyworld_current_members%
%gtmyworld_current_core_health%

核心与排行变量 ​

text
%gtmyworld_core_health%
%gtmyworld_core_max_health%
%gtmyworld_core_health_percent%
%gtmyworld_core_protection_seconds%
%gtmyworld_core_contributors%
%gtmyworld_rank_level%
%gtmyworld_rank_members%
%gtmyworld_rank_visits%
%gtmyworld_rank_likes%

排行榜指定名次：

text
%gtmyworld_rank_level_1_name%
%gtmyworld_rank_level_1_owner%
%gtmyworld_rank_level_1_value%
%gtmyworld_rank_likes_3_name%

排行类型支持 level、members、visits、likes，末尾字段支持 name、owner、value、level、server。

权限变量 ​

查询当前玩家在自己所属家园的某项权限：

text
%gtmyworld_permission_chest%
%gtmyworld_permission_build%
%gtmyworld_permission_manage_members%

权限 ID 与 permissions.yml 一致，下划线和配置中的连字符对应。
